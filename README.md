# SLoG-Net Example

Welcome to the SLoG-Net example repository. This repository contains an example implementation of SLoG-Net, a framework for source localization on graphs.

## Getting Started

To run the example, you can either execute the provided Jupyter notebook or run the experiment script directly.

### Running the Jupyter Notebook

Open and run the `SLoG-Net-example.ipynb` notebook to see the example in action.

### Running the Experiment Script

Alternatively, you can run the experiment script using the following command:

```bash
python run_experiment.py --output_file "output_results.json" --useGPU True
```
